# フランス語のエリジオンとリエゾンを全ランタイムで Python に合わせる (#822、2026-10-23)

## 1. 何が起きていたか

Python の `french.py` は、単語に分ける段階でエリジオン (`l'ami` → `lami`) とリエゾン (`les amis` の /z/) を扱います。
ほかのランタイムは次のように違っていました。

| ランタイム | 修正前の動作 | 例 |
|---|---|---|
| C++ / Rust (WASM・Swift を含む) / `@piper-plus/g2p` | アポストロフィを空白にして別の語にする。リエゾンなし | `c'est` が `c` + `est` になり、`Je m'appelle` の `m` は語末の無音子音として消える |
| Go | 同上。さらに `unicode.IsLetter` で語を切るので、Python が捨てる文字も語に入る | 同上 |
| C# CLI | 外部ライブラリ DotNetG2P.French の規則で読む | ɛ / œ / 鼻母音の読みが違い、正解との差が 15 件 |

正解ファイルにはエリジオンとリエゾンを含むケースが 3 件しかなかったので、
両方を確かめる 25 件 (`l'` `d'` `j'` `n'` `s'` `qu'` `t'`、典型的なアポストロフィ、h 無音、
限定詞・代名詞・数詞・前置詞・動詞のリエゾン、子音の前と句読点越しでは起きないこと) を追加しました。

## 2. Python の規則

- **正規化**: 前後の空白を除き、NFC、小文字化、連続空白を 1 つにする。
- **単語分割** (`_split_words`): `’` `‘` を `'` にそろえる。語は `[a-zàâæéèêëîïôùûüœçñ]` の並びで、英字に挟まれた `'` を含めてよい。
  `, . ; : ! ? ¡ ¿ — – … « »` は 1 文字で 1 トークンです。それ以外の文字は捨てます。
  語を `'` で分け、エリジオン接語 (`l d j n s c m t qu`) が出たら、それ以降の部分を全部つなげて 1 語にします。
  接語でない部分はそれぞれ 1 語です (`aujourd'hui` → `aujourd` + `hui`)。
- **リエゾン** (`_apply_liaison`): 語がリエゾン語の表 (38 語) にあり、次のトークンが語で、母音字か「h + 母音字」で始まるとき、その語の音素の最後に連結子音 (`z` / `n` / `t`) を足します。
  連結子音はその語の一部として韻律 (A3) を数えます。句読点を挟むと起きません。

## 3. 移植

| ランタイム | 変更 |
|---|---|
| C++ `french_phonemize.cpp` | `splitWords` を 2 章の規則に置き換え、`phonemize_french` でリエゾンを足す |
| Rust `piper-plus-g2p/src/french.rs` | 同上。WASM (piper-wasm) と Swift (C FFI) もこの実装を使う |
| Go `phonemize/french.go` | 同上。語の文字を Python と同じ集合に限定した |
| JS `wasm/g2p/src/fr/index.js` | 同上。共通の `tokenize` は使わなくなった |
| C# `PiperPlus.Core/Phonemize/FrenchG2PEngine.cs` | Python の `_convert_word` を含めて新しく移植した。CLI とベンチマークはこれを使い、DotNetG2P.French への依存を外した |

C# は、DotNetG2P.French を残したまま差を埋めるより、Python の規則を直接移植するほうが確実なので、
中国語の `PinyinDictionaryChineseG2PEngine` と同じく PiperPlus.Core にエンジンを置きました。

## 4. 結果とテスト

- 全ランタイムでフランス語の差が 0 件になったので、`known_divergences.json` からフランス語の 18 項目を削除しました。
  記録にあるのに一致したら失敗するので、これ以降の回帰は各ランタイムの照合テストで検出されます。
- 単体テスト: Go `TestFrSplit` (接語の結合、接語でない部分、英字が続かないアポストロフィ、句読点、捨てる文字)、
  C# `FrenchG2PEngineTests` (Python の出力を期待値にした語と文)。
- h 有音 (`héros` など) の区別、任意のリエゾン、アンシェヌマンは Python も扱わないので、移植でも扱いません。
